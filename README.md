# 栈川行 · V3 智能博物馆伴游

**陪你走完一段历史。** 面向长征主题纪念馆游客的移动 Web App，以「走 · 听 · 看」组织参观体验。当前是可运行、可部署的高保真功能原型，并非已接入实际场馆的生产系统。

## 这次改了什么

- 首页从内容门户改为旅程控制台：30 / 45 / 60 分钟选择、当前站、预计剩余、继续导览。旅程刷新后可恢复。
- 地图明确入口或已确认的位置、目标展厅、示意路径与距离；到站由游客手动确认。更换路线需确认，足迹和收藏不丢失。
- 五段真实普通话合成讲解：可拖动、前后跳 15 秒、调速、分段字幕和完整文字稿。跨页持续播放、全局迷你播放器；支持浏览器的 Media Session 控件。
- 展厅详情分为史实摘要、编辑讲解、史料与出处；链接仅为官方资料入口，未冒充已核验的原始文献。
- 现场观察任务优先，知识答题退居第二层；机器人带路状态与投影队列使用应用级演示状态。

## 本地运行与测试

建议 Node.js 24 LTS（测试和语音生成脚本依赖原生 TypeScript 类型擦除），无需数据库。

```bash
npm ci
npm run dev
```

浏览器打开终端给出的地址。不是双击源码 `index.html`；TSX 与资源需要开发或静态 HTTP 服务器。手机同网测试可运行 `npm run dev -- --host`，再访问电脑局域网地址，请仅在可信网络使用。

```bash
npm test
npm run build
npm run preview
```

测试覆盖三条路线推进、断点状态校验、时间预算、示意路线避开其他展厅、五段 WAV 与字幕/脚本文本对应。`dist/` 是完整静态部署产物，包含音频，须整体上传；本机预览时保持服务运行。

## 发布与更新

仓库 `.github/workflows/deploy-pages.yml` 在 `main` 更新后自动测试、构建并发布 GitHub Pages。仓库 Settings → Pages 的 Source 应为 **GitHub Actions**。

站点地址：<https://zluo7467-debug.github.io/zhanchuanxing/>。

本地改动不会直接更新公网：需要提交、推送到 `main`，等 Actions 成功后网页才更新，原网址不变。不要把 `dist/index.html` 单独覆盖仓库根目录的源码入口。

也可导入 Vercel / Netlify 等平台：构建命令 `npm run build`，发布目录 `dist`。当前无后端环境变量。

## 讲解资源

`public/audio/*.wav` 是本机 Microsoft Huihui Desktop 生成的合成语音，并非馆方配音。`narration.json` 存储按真实音频长度生成的段落时间点。音频共约 15.6 MB，按选择的展厅加载，不预下载整套。

在已安装中文语音的 Windows PowerShell 7 环境重新生成：

```powershell
./scripts/generate-narration.ps1
npm test
```

先编辑 `src/evidence.ts` 中的讲解，再生成音频和字幕并一起提交。正式上线前需要馆方审定与专业配音，替换后同步更新时长/字幕。锁屏继续播放取决于系统与浏览器，须进行 iPhone / Android 真机测试，不能保证所有设备或省电设置下持续播放。

## 数据与离线边界

- 足迹、收藏、观察印记、字号及旅程仅保存在本浏览器；没有账户同步，不收集真实定位。
- 关闭存储权限仍可使用，但不保证刷新后恢复。旧版足迹键保留迁移兼容。
- 生产环境缓存应用壳及成功访问过的同源普通资源，网络失败时尽力回退；不是完整离线包。音频 Range 请求和 WAV 不由 Service Worker 缓存，离线音频下载待实现。
- 机器人与投影刷新后重置，避免显示虚假的硬件重连；展厅进度不会因此丢失。

## 正式入馆前必须补齐

1. 场馆实测地图、楼层/无障碍路径、安全与疏散导视；二维码/BLE/UWB 的定位接口和误差处理。
2. 机器人会话绑定、实时遥测、导航任务、失联/急停与工作人员接管；目前 A07、电量和距离均明确标作演示。
3. 授权影片、真实投影设备控制、共享占用/排队、权限与多人冲突；目前没有播放实际影片。
4. 逐条史料出处、藏品编号、版权与馆方内容审核；观察任务与实物一一核对。
5. 隐私政策、必要的服务端鉴权、日志与运维、异常处理、无障碍审查、弱网/真机与现场可用性测试。
